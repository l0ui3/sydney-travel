# 雪梨數位遊牧行程表 · Sydney Digital Nomad Itinerary

9/3（四）– 9/12（六）雪梨十日行程單頁網站：平日 12:00–21:00 遠端工作，早晨與夜晚探索雪梨。

## 內容

- **航班資訊** — OD121 去程 / OD120 回程登機證樣式卡片
- **十日一覽** — 甘特圖式時間軸，一眼看出每天的工作時段與空檔
- **每日行程** — 10 天逐日時間表，含分類標籤（晨間觀光 / 遠端工作 / 晚餐夜生活 / 交通）與提醒
- **行前備忘** — 需預約項目、各景點開門時間、交通與回程注意事項

## 開發

`index.html` 是完全獨立的單一檔案（行程資料在檔尾的 `DAYS` 陣列，甘特圖與每日卡片皆由此渲染），沒有建置步驟與相依套件。

```bash
python3 -m http.server 8000   # 然後開啟 http://localhost:8000
```

修改行程只需編輯 `DAYS` 陣列：每個項目的 `s` / `e` 用於甘特圖定位，`time` / `to` 為卡片上顯示的文字。

## 部署

任何靜態網站主機皆可（GitHub Pages、Netlify、Cloudflare Pages）；只需 `index.html` 一個檔案。網頁字型來自 Google Fonts，需要對外連線。

時間皆為雪梨當地時間（AEST, UTC+10）。
